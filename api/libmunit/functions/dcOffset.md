# Function: dcOffset()

```ts
function dcOffset(values): number;
```

The mean of a list of numbers, i.e. the DC offset of a signal; 0 for no
samples. The `dc` helper.

## Parameters

| Parameter | Type |
| ------ | ------ |
| `values` | `unknown` |

## Returns

`number`

## Throws

TypeError when `values` isn't a number or a list of them
