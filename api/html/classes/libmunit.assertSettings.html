    Class assertSettings

    One assert as registered with the handler: its attributes and what it evaluates. Result formatters get the list of these as their first argument.

    Properties

    maxCalls

    maxCalls: number = 1

    @maxCalls: how many calls the assert may take to reach a verdict. Default 1.

    timeout

    timeout: number = -1

    @timeout: milliseconds from the first input (or the suite start) before a call counts as failed; -1 (the default) for none.

    tolerance

    tolerance: number = 0

    @tolerance, custom and @every asserts: how many Fail results are tolerated before failing.

    name

    name: string | null = null

    @name, or the uuid when the assert has none.

    suite

    suite: string | null = null

    @suite, or the name of the patch the assert sits in.

    accumulate

    accumulate: boolean = false

    @accumulate: inputs are summed across calls instead of replaced.

    dataInlets

    dataInlets: number = 1

    @dataInlets: how many data inlets the assert reads (in1..inN).

    uuid

    uuid: string | null = null

    The assert object's unique id, which the results carry too.

    kind

    kind: AssertKind = 'expression'

    What kind of assert this is.

    expression

    expression: string | null = null

    The expression, the custom script's file name, or the reference file.

    every

    every: boolean = false

    @every, expression asserts: every call must be true (e.g. a table of cases), rather than any one of them.

    skip

    skip: boolean = false

    @skip: report the assert as Skipped without evaluating it.

    only

    only: boolean = false

    @only: when any assert in the suite has it, every other one is Skipped.

    reference

    reference: string | null = null

    @reference, signal and matrix asserts: the reference file (next to the test patch, in references/) the capture is compared with; null for an expression.

    snr

    snr: number = 60

    @snr, signal asserts: the least signal-to-noise ratio, in dB, that counts as a match (60 dB is about 0.1% of the signal).

    maxLatency

    maxLatency: number = 0

    @maxLatency, signal asserts: how many samples the capture may lead or lag the reference; 0 compares them as they are.

    exact

    exact: boolean = false

    @exact, signal asserts: every sample must be identical (bit-exact).

    maxDiff

    maxDiff: number = 0

    @maxDiff, matrix asserts: the largest difference a cell may have from the reference, in the matrix's units (0-255 for char).

    maxFraction

    maxFraction: number = 0

    @maxFraction, matrix asserts: the largest fraction of cells (0 to 1) that may exceed maxDiff.
