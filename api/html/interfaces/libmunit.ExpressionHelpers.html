    Interface ExpressionHelpers

    The helpers in scope in an expression (approx(in1, 0.5)) and passed to a custom assert as its second argument. The comparisons (approx, equals, snapshot, sameMatrix) record what they compared, so a failure reports expected and actual values and the differences without more work. The measures (rms, peak, ...) are the library functions of the same name.

    interface ExpressionHelpers {
        approx: (
            actual: unknown,
            expected: unknown,
            abs?: number,
            rel?: number,
        ) => boolean;
        equals: (actual: unknown, expected: unknown) => boolean;
        snapshot: (actual: unknown, name?: string) => boolean;
        rms: (values: unknown) => number;
        peak: (values: unknown) => number;
        dc: (values: unknown) => number;
        maxDiff: (actual: unknown, expected: unknown) => number;
        snr: (actual: unknown, reference: unknown) => number;
        freq: (values: unknown) => number;
        planeMin: (matrix: unknown, plane?: number) => number;
        planeMean: (matrix: unknown, plane?: number) => number;
        planeMax: (matrix: unknown, plane?: number) => number;
        cell: (
            matrix: unknown,
            x: number,
            y?: number,
            plane?: number,
        ) => number | number[];
        sameMatrix: (
            actual: unknown,
            expected: unknown,
            maxDiff?: number,
            maxFraction?: number,
        ) => boolean;
    }

    Properties

    approx

    approx: (
        actual: unknown,
        expected: unknown,
        abs?: number,
        rel?: number,
    ) => boolean

    Whether actual equals expected within a tolerance, compared like deepEqual: lists item by item, dicts key by key. The tolerance is the larger of abs (default 1e-6) and rel * |expected| (default 0).

    equals

    equals: (actual: unknown, expected: unknown) => boolean

    Whether actual equals expected exactly, compared like deepEqual.

    snapshot

    snapshot: (actual: unknown, name?: string) => boolean

    Whether actual matches the reference <patch folder>/references/<name>.json. The name defaults to the assert's @name; it must have one or be given one here, and the patch must be saved, or the helper throws. With no reference yet the check fails and says how to take one; when taking references the value is written as the reference and the check passes.

    rms

    rms: (values: unknown) => number

    The root mean square, as rms.

    peak

    peak: (values: unknown) => number

    The largest absolute value, as peak.

    dc

    dc: (values: unknown) => number

    The mean, as dcOffset.

    maxDiff

    maxDiff: (actual: unknown, expected: unknown) => number

    The largest absolute difference between two lists, as maxDiff.

    snr

    snr: (actual: unknown, reference: unknown) => number

    The signal-to-noise ratio in dB, as snrDb.

    freq

    freq: (values: unknown) => number

    The frequency in Hz of a captured signal, as frequency at the capture's sample rate. Signal asserts ([mUnit.assert~]) only: anywhere else it throws, since there is no sample rate.

    planeMin

    planeMin: (matrix: unknown, plane?: number) => number

    The smallest value in one plane (default 0) of a matrix, as planeStats.

    planeMean

    planeMean: (matrix: unknown, plane?: number) => number

    The mean of one plane (default 0) of a matrix, as planeStats.

    planeMax

    planeMax: (matrix: unknown, plane?: number) => number

    The largest value in one plane (default 0) of a matrix, as planeStats.

    cell

    cell: (
        matrix: unknown,
        x: number,
        y?: number,
        plane?: number,
    ) => number | number[]

    One cell of a matrix, as matrixCell: its planes as a list, or one plane's value.

    sameMatrix

    sameMatrix: (
        actual: unknown,
        expected: unknown,
        maxDiff?: number,
        maxFraction?: number,
    ) => boolean

    Whether two matrices match, as matchMatrix with maxDiff and maxFraction (both default 0: identical). Records a check, so a failure reports both shapes and how many cells differed.
