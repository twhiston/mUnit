    Interface Outcome

    What a custom assert returns instead of a bare State to say more about a call: a message, the expected and actual values, and files to keep with a failure. Only state is required. Details given here replace what the helpers recorded.

    Example

    return {
      state: mLib.State.Fail,
      message: "the inputs should add up to 10",
      expected: 10,
      actual: sum,
      attachments: [{ name: "inputs.txt", content: values.join("\n") }],
    };
    interface Outcome {
        state: State;
        message?: string;
        error?: string;
        expected?: unknown;
        actual?: unknown;
        operator?: string;
        diff?: string[];
        attachments?: Attachment[];
        recordings?: Recording[];
    }

    state

    state: State

    The verdict of this call.

    Optionalmessage

    message?: string

    Replaces the default description of a failure in the results and the console.

    Optionalerror

    error?: string

    An exception, or a contract the evaluator broke; reported as an error rather than a failure.

    Optionalexpected

    expected?: unknown

    The value the assert expected.

    Optionalactual

    actual?: unknown

    The value it got.

    Optionaloperator

    operator?: string

    The comparison's operator, when there was one.

    Optionaldiff

    diff?: string[]

    Every difference, one path: expected X, got Y line each, as from diffValues.

    Optionalattachments

    attachments?: Attachment[]

    Files to keep with a failure.

    Optionalrecordings

    recordings?: Recording[]

    Reference files written when taking references.
