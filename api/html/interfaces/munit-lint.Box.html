    Interface Box

    One box in a patcher: an object, message, comment or UI object.

    interface Box {
        id: string;
        maxclass: string;
        text: string | null;
        object: string | null;
        args: string[];
        attributes: Record<string, unknown>;
        varname: string | null;
        rect: [number, number, number, number] | null;
        patcher: Patcher | null;
        raw: Record<string, unknown>;
    }

    Properties

    id

    id: string

    Max's id for the box, e.g. obj-12, unique within its patcher.

    maxclass

    maxclass: string

    Max's class: newobj for an object box, message, comment, toggle, ...

    text

    text: string | null

    The box text as saved (newobj, message, comment); null for UI objects.

    object

    object: string | null

    What the box is: the normalised first token of a newobj's text (aliases resolved, so [t] and [trigger] are both trigger, and [zl reg] is zl.reg), otherwise the maxclass.

    args

    args: string[]

    Positional arguments after the object name, up to the first @attribute.

    attributes

    attributes: Record<string, unknown>

    Inline @attributes from the text (a single value as a string, several as a list of tokens) merged over the attributes Max saved on the box.

    varname

    varname: string | null

    The scripting name, or null.

    rect

    rect: [number, number, number, number] | null

    patching_rect: x, y, width, height.

    patcher

    patcher: Patcher | null

    A nested patcher: [p], [gen~], [jit.gen], [rnbo~] and friends.

    raw

    raw: Record<string, unknown>

    The box's JSON as saved, for anything the model doesn't name.
