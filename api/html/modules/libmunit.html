    Module libmunit

    The public JavaScript API of mUnit: what a custom assert, a log or result formatter and a munit.config.js can rely on.

    In Max, require("libmunit") returns it (the package puts libmunit.js on the search path). In an editor, add the package's api/libmunit.d.ts to a jsconfig.json next to your scripts, as every example under examples/ does, and annotate what you write:

    /// munit.config.js
    /** @type {import("libmunit").HandlerConfig} */
    module.exports = { resultFormatter: "JUnit", outputDir: "./logs" };
    • A custom assert is an AssertionHandler: it gets the inputs and the ExpressionHelpers, and returns a State or an Outcome.
    • A formatter implements LogFormatter or ResultFormatter and receives assertSettings, assertState and finalisedResults.
    • A munit.config.js exports a HandlerConfig.
    • The measures (rms, snrDb, matchMatrix, ...) are the functions behind the helpers, for scripts that want them directly.

    Anything require("libmunit") returns that is not listed here is internal and may change without notice.
