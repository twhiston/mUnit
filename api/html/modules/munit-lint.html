    Module munit-lint

    The API a script lint rule is written against: the patcher model, the context the rule's check receives, and the findings and edits it reports.

    A script rule is a JSON rule of kind script whose module names a JavaScript file exporting check(ctx). Nothing is required at runtime: everything arrives through ctx. For completion and checking in an editor, add the package's api/munit-lint.d.ts to a jsconfig.json next to the module (as examples/lintExample does) and annotate it:

    /** @type {import("munit-lint").ScriptCheck} */
    exports.check = (ctx) => {
      for (const patcher of ctx.patchers) {
        for (const box of patcher.boxes) {
          if (box.object === "print" && box.args.length === 0) {
            ctx.report({ box, message: "give [print] a name" });
          }
        }
      }
    };

    Script rules run wherever the lint runs: under munit lint, and inside [mUnit.lint] in Max, whose server is a node.script and loads the module the same way. The module is CommonJS (exports.check).
