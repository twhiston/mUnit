# Interface: FileRules

The rules in force for one file, from `--list-rules`.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="file"></a> `file` | `string` | The file, as reported. |
| <a id="rules"></a> `rules` | [`RuleListing`](RuleListing.md)[] | Every rule in force, in order. |
