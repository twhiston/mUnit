# Interface: Line

A patch cord.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="source"></a> `source` | \[`string`, `number`\] | The box id and outlet number it starts from. |
| <a id="destination"></a> `destination` | \[`string`, `number`\] | The box id and inlet number it ends at. |
| <a id="disabled"></a> `disabled` | `boolean` | Whether the cord is disabled. |
| <a id="raw"></a> `raw` | `Record`\<`string`, `unknown`\> | The cord's JSON as saved. |
